# FitPro - Фитнес-тренер PWA

Прогрессивное веб-приложение для отслеживания тренировок в спортзале.

## Функции

- 6 пользователей - каждый со своим прогрессом
- Программы тренировок - Грудь+Трицепс, Спина+Бицепс, Ноги+Плечи
- Разминка на кардио - Беговая дорожка, Гребной тренажёр, Велотренажёр
- Анимации упражнений - GIF-демонстрации для каждого упражнения
- Прогрессия весов - автоматический подбор рабочего веса
- Система персонажей - 2 аватара с 4 уровнями прокачки
- Таймер отдыха - настраиваемый таймер между подходами
- Замена упражнений - выбор альтернативы из той же группы мышц
- Калькулятор 1RM - расчёт максимума по разным формулам
- Экспорт/Импорт - резервное копирование данных
- PWA - установка на телефон как приложение

## Структура файлов

- index.html - Главное приложение
- manifest.json - PWA манифест
- sw.js - Service Worker для оффлайн-работы
- icon.svg, icon-192.svg, icon-512.svg - Иконки
- muhamed_1-4.png - Аватар "Лысый" (4 уровня)
- nikolay_1-4.png - Аватар "Лохматый" (4 уровня)
- exercises/ - GIF-анимации упражнений (35 файлов)

## Установка на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы из этой папки
3. Settings -> Pages -> Source: main branch
4. Сайт доступен по адресу: https://ваш-логин.github.io/имя-репо/

## Установка как приложение

1. Откройте сайт в Chrome/Safari
2. Chrome: Меню -> "Установить приложение"
3. Safari (iOS): Поделиться -> "На экран Домой"

## Уровни персонажей

| Уровень | Тренировок | Название |
|---------|------------|----------|
| 1 | 0-19 | Новичок |
| 2 | 20-49 | Любитель |
| 3 | 50-99 | Спортсмен |
| 4 | 100+ | Атлет |

## Технологии

- Vanilla JS (без фреймворков)
- CSS Grid и Flexbox
- LocalStorage для данных
- Service Worker для PWA
